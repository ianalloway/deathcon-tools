# Deathcon Tools

Ian Alloway's personal CLI toolkit.

## Tools

| Tool | Purpose |
|------|---------|
| dc.py | Unified launcher |
| dashboard.py | Mission Control dashboard |
| pio.py | Morning briefings |
| meeting.py | Meeting notes |
| learn.py | Learning tracker |
| standup.py | Daily standup |
| note.py | Quick notes |
| time.py | Time tracking |
| alert.py | Alert system |
| bookmark.py | Bookmarks |
| health.py | System health |
| snippets.py | Code snippets |
| auto_respond.py | Q&A about Ian |
| social_poster.py | Tweet generator |
| readme.py | README generator |
| webhook.py | Webhook handler |
| api_server.py | REST API server |

## Usage

```bash
python3 dc.py list
python3 dashboard.py
python3 api_server.py
```

## API

Run `python3 api_server.py` then visit:
- Dashboard: http://localhost:8080/dashboard.html
- API: http://localhost:8080/api
